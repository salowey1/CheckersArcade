# Checkers Arcade

## Дизайн-документ

### Краткое описание

Checkers Arcade - настольная аркадная игра по мотивам шашек. Игроки по очереди двигают красные и синие шашки по диагоналям, захватывают фигуры соперника и используют дополнительную механику столкновений: после взятия или взрыва шашки соседние фигуры начинают скользить по полю и занимают новые свободные темные клетки.

### Жанр и платформа

- Жанр: логическая настольная игра с аркадной физикой.
- Режим: локальная игра для двух игроков за одним компьютером.
- Платформа: Windows x64.
- Технологии: C#, .NET 8, MonoGame DesktopGL.

### Цель игры

Победить соперника одним из двух способов:

- убрать с поля все шашки соперника;
- оставить соперника без доступных ходов.

### Основная идея

Игра сохраняет понятную основу классических шашек, но добавляет непредсказуемость за счет физического смещения фигур. После взятия или намеренного взрыва шашки на поле возникает импульс, из-за которого другие шашки могут сдвинуться, столкнуться и изменить позицию. Благодаря этому партия становится более динамичной, а игрокам приходится учитывать не только текущие ходы, но и возможное изменение расстановки.

### Игровой процесс

1. На экране меню игрок выбирает размер поля.
2. Красные начинают первыми.
3. Игрок выбирает свою шашку кликом мыши.
4. Доступные клетки подсвечиваются зелеными маркерами.
5. Игрок кликает по доступной клетке, чтобы выполнить ход.
6. Если ход был взятием, шашка соперника удаляется, появляется визуальный эффект, а остальные фигуры могут начать скользить.
7. После завершения движения ход переходит к другому игроку.
8. Игра заканчивается, когда один из игроков побеждает.

### Правила

- Ходить можно только по диагонали и только на темные клетки.
- Обычная шашка ходит вперед на одну клетку.
- Взятие выполняется через шашку соперника на свободную клетку за ней.
- Взятие не является обязательным: игрок может выбрать обычный ход.
- Дамка может ходить по диагонали на любое количество свободных клеток.
- Дамка может брать фигуру соперника на диагонали, если за ней есть свободная клетка.
- Шашка становится дамкой, когда доходит до противоположного края поля.
- Двойной клик по своей шашке взрывает ее вместо обычного хода.
- После взятия или взрыва запускается аркадная механика скольжения фигур.

### Управление

- Левый клик по своей шашке - выбрать шашку.
- Левый клик по подсвеченной клетке - сделать ход.
- Двойной клик по своей шашке - взорвать выбранную шашку.
- `Esc` во время игры - вернуться в меню.
- `Esc` в меню - выйти из игры.

### Интерфейс

В игре есть два основных состояния:

- Главное меню: выбор размера поля, запуск игры, переход к правилам, выход.
- Игровой экран: доска, шашки, подсветка доступных ходов, счетчик фигур, текущий ход и сообщение о победителе.

Размер поля выбирается в меню. Поддерживаются четные размеры от 4 x 4 до 16 x 16. Доска автоматически масштабируется под размер окна.

### Визуальный стиль

Визуальный стиль минималистичный и контрастный:

- поле выполнено в светлых и темных клетках;
- красные и синие шашки показывают стороны игроков;
- выбранная шашка подсвечивается белым цветом;
- доступные ходы отмечаются зелеными маркерами;
- дамка получает золотую отметку;
- при взятии и взрыве появляется короткий эффект вспышки.

### Техническая реализация

Проект разделен на несколько логических частей:

- `Game1.cs` - основной игровой цикл, переключение между меню и игрой, обработка окна и ввода.
- `UI/MenuScreen.cs` - главное меню и экран правил.
- `Screens/GameScreen.cs` - связывает модель, контроллер и представление игрового экрана.
- `Controllers/CheckersGameController.cs` - обработка кликов мыши и передача команд модели.
- `Models/CheckersBoardModel.cs` - состояние доски, ходов, фигур, победы и окончания партии.
- `Models/CheckersRules.cs` - правила перемещения, взятия и превращения в дамку.
- `Models/SlidingPhysicsModel.cs` - аркадное скольжение фигур после взятия или взрыва.
- `Views/GameView.cs` - отрисовка доски, фигур, HUD и эффектов.

Архитектура близка к схеме MVC: модель хранит состояние и правила, контроллер обрабатывает ввод, представление отвечает за отображение.

### Сборка и запуск из исходного кода

1. Откройте проект в Visual Studio.
2. Откройте файл `CheckersArcade.csproj`.
3. Соберите и запустите проект.

Также проект можно собрать из командной строки:

```text
dotnet build
dotnet run
```

### Запуск готового билда

В папке `build` запустите файл:

```text
CheckersArcade.exe
```

Билд предназначен для Windows x64 и не требует установки дополнительного ПО.

### Структура архива для сдачи

```text
Фамилия Имя Отчество студента.zip
├── source code
└── build
```

В папке `source code` должен лежать исходный код игры, который можно открыть через Visual Studio. В папке `build` должен лежать готовый билд игры.
